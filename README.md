## 🎯 Purpose of This Repository

This repository is an **intensive, production-grade preparation guide and architectural reference** designed for senior engineers transitioning from enterprise backend/low-code development (Mendix, Core Java microservices, PostgreSQL) into **Senior Full-Stack Developer** and **Decoupled Architecture Lead** roles.

Rather than shallow beginner tutorials, this repository focuses on:
- **Mental Models & Internals:** Virtual DOM Fiber reconciliation, Event Loop microtasks, and pure rendering.
- **Enterprise Patterns:** TanStack Query server-state caching, optimistic updates, and Zustand global stores.
- **Decoupled "React on Mendix" Architecture:** Headless Mendix 11 REST, in-browser React Flow 12 workflow engines, and Model-as-Code via `mxcli`.
- **Production Hardening:** 74 Playwright E2E journeys, Arabic (RTL) localization, WCAG 2.1 AA accessibility, and JWT `HttpOnly` security.
- **Senior Interview Playbook:** Strategic scripts to break the 30% CTC trap, leverage 90-day notice periods, and pass UAE & Big 4 technical rounds.

## 📅 8-Week Preparation Sprint Plan

| Week | Focus Area | Hands-on Milestone |
| :---: | :--- | :--- |
| **Week 1** | Modern TypeScript & Runtime Internals | Master Generics, Discriminated Unions, and Event Loop edge cases. |
| **Week 2** | React 18 Hooks & Reconciliation | Build complex forms using `useReducer` and custom validation hooks without `useEffect`. |
| **Week 3** | Server State with TanStack Query v5 | Implement live data tables with query invalidation, caching, and optimistic rollbacks. |
| **Week 4** | Interactive Canvas (React Flow 12) | Build an interactive workflow graph editor that outputs a serialized JSON schema. |
| **Week 5** | Full-Stack Next.js 15 App Router | Build an authenticated CRUD app using Server Components, Server Actions, and Postgres. |
| **Week 6** | Enterprise Security & Auth | Implement JWT auth with `HttpOnly` SameSite cookies, RBAC guards, and CSRF protection. |
| **Week 7** | Automated Testing & Accessibility | Author Vitest component tests and automated Playwright E2E suites with `@axe-core`. |
| **Week 8** | Mock Interviews & CTC Negotiation | Rehearse top 50 technical interview questions and finalize counter-offer strategy. |
